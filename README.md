# Eventuary BFF

BFF for Eventuary app

## Getting started

1. Install npm version XXXXXX
2. Setup .env using .env.example as a baseline

```shell
cp .env.example .env
```

3. Install dependencies

```shell
npm install
```

## Run projects

```shell
npm run dev
```

```shell
npm run build
npm run start
```

## Run tests

```shell
npm run test
```
